# Night-time slowdown/crash report

Status: unresolved. The report concerns the published v0.3.0 build on Old 3DS, where night-time play could lag or crash.

The same report described containers closing on B release. The [v0.4.11 container input fix](container-release.md) addresses that separate input behavior; it does not establish a fix for the night-time failure.

The night-time crash needs its own dump and reproduction. It must not be attributed to unshipped optimization experiments without evidence. Neither the later memory-headroom changes nor successful short emulator runs establish its cause or resolution.
